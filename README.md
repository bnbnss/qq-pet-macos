# QQ宠物 1.6.1 最终版

经典 QQ 宠物 Electron 桌面客户端，基于 Ruffle (Flash) 运行原始 SWF 动画，还原 2005 年的养宠体验。

## 功能一览

- 领养企鹅、喂食/清洁/治疗/玩耍全套互动
- 商城购物（食品/日用品/药品/装扮/旅行）
- 签到奖励（12天递增）+ 在线时长奖励（8档）
- 右键菜单：宠物档案、设置、商城、旅行、工作、学习
- 快捷键系统（截图等）
- 气泡对话系统（内置语料 + LLM 可选）
- 托盘图标 + 系统通知
- 专注守护提醒（护眼/久坐/深夜/超时未使用）

## 快速开始

1. 下载 release 或 clone 本仓库
2. 双击 `启动宠物.bat`
3. 首次运行会进入领养界面

## 构建

需要 Node.js 18+

```bash
cd 源代码
npm install
npx electron-builder --win dir
```

输出在 `dist/win-unpacked/`

## 项目结构

```
├── 启动宠物.bat          # 双击启动
├── 清除缓存.bat          # 清缓存+关进程
├── 使用说明.txt
├── QQ宠物/              # 运行文件（构建产物）
└── 源代码/              # 完整源码 + git 仓库
```

## 技术栈

- Electron 28 + Node.js
- Ruffle (Flash SWF 渲染)
- Vue 3 (UI)
- Webpack (模块打包)
